Перелік документів для укладання договору

Для швидкого переходу на постачання до Think Energy без паперової тяганини підготуйте електронні копії наступних документів для підписання через Вчасно або M.E.Doc:

✓
1. Заява-приєднання
За встановленою формою з обраною комерційною пропозицією.
✓
2. Витяг з ЄДР
Актуальний витяг з Єдиного державного реєстру юридичних осіб.
✓
3. Статут підприємства
Копія чинної редакції Статуту або код доступу на порталі Мін'юсту.
✓
4. Наказ на право підпису
Документ, що підтверджує повноваження керівника або довіреність.
✓
5. Свідоцтво платника ПДВ
Або витяг з реєстру платників податку на додану вартість.
✓
6. Документ на право власності
Договір оренди або свідоцтво на об'єкт газо-/електроспоживання.
✓
7. Довідка про присвоєння EIC-коду
Витяг від Оператора ГРМ (облгазу) або Оператора системи розподілу (обленерго) про закріплені EIC-коди точок обліку.
